# 1단계: 요구사항·운영 정책

작성일: 2026-11-10

근거: [README](../README.md)의 확정 요구사항과 사용자의 기본값 결정 위임. 기존 문서의 미확정 항목 중 아래에 명시한 기본값은 이번 개발 기준으로 채택한다. 실제 판매 자료와 외부 서비스 계약 정보는 준비가 필요하다.

## 1. 개발 기본값

| 항목 | 채택 값 | 적용 범위 |
|---|---|---|
| 서비스명 | 청년농부 장터 | 웹앱 제목·텍스트 로고. 도메인·상표 확보를 의미하지 않음 |
| 판매 범위 | 국내 배송, 제철 채소·과일 단품·상품 옵션 | 정기배송·가공식품·해외 배송 제외 |
| 고객 | 개인·사업자 | 개인 구매와 사업자 견적 문의 제공 |
| 회원 로그인 | 이메일·비밀번호, 이메일 확인, 비밀번호 재설정 | 소셜 로그인은 초기 제외 |
| 비회원 주문조회 | 주문번호와 주문 이메일로 일회용 확인 링크 발송 | 주문번호만으로 개인정보 열람 불가 |
| 결제 | 원화 국내 카드 결제, PG 테스트 환경 우선 | PG 제공사·계약·키는 3단계에서 준비 |
| 농부 주문 전달 | 농부별 등록 이메일로 자동 발송 | 각 농부의 발송 대상 주문만 포함 |
| 고객 알림 | 이메일 | 재입고·수확 판매 시작을 별도 신청·해지 |
| 운영 방식 | 공동 운영자 통합 관리 | 농부 전용 로그인·관리 화면 제외 |
| 견적 회신 목표 | 영업일 기준 2일 이내 1차 회신 | 자동 견적 확정·공급 보장 아님 |
| 디자인 | 크림·짙은 초록, Pretendard, 얇은 선·작은 라벨 | 세 가닥 강조 장식 전체 제외. 최종 화면 검수 별도 |

## 2. 기능 명세와 인수 기준

모든 항목은 초기 오픈 범위다. ID는 후속 화면·API·검수 문서에서 공통으로 사용한다.

| ID | 기능 | 인수 기준 |
|---|---|---|
| F01 | 홈페이지·기본 메뉴 | 제철 장터·농부 소개·우리의 이야기·사업자 대량구매·고객센터와 구매 진입점 제공 |
| F02 | 상품 탐색 | 상품명 검색, 채소·과일 및 농부 필터, 결과 없음·로딩·실패 상태 제공 |
| F03 | 상품 상세 | 가격·규격·원산지·농부·수확/발송 예정·보관법·배송비 표시. 확인된 인증만 표시 |
| F04 | 회원 | 가입·이메일 확인·로그인·로그아웃·비밀번호 재설정 제공. 비밀번호 원문 저장 금지 |
| F05 | 장바구니 | 옵션·수량 변경, 품절 제한, 농부별 상품 묶음과 배송비·총액 표시 |
| F06 | 회원·비회원 결제 | 서버에서 가격·재고·배송비 재검증. 결제 검증 후 주문 확정. 중복 요청으로 중복 주문·차감 방지 |
| F07 | 주문·배송조회 | 회원은 본인 주문만, 비회원은 이메일 확인 후 해당 주문만 조회. 농부별 상태·운송장 구분 |
| F08 | 취소·환불 | 농부별 배송 묶음 또는 상품 단위 요청·운영자 처리 지원. 부분 취소·배송비 재계산 결과 표시 |
| F09 | 통합 관리자 | 상품·옵션·재고·농부·주문·운송장·콘텐츠·문의 관리. 일반 고객 접근 차단 |
| F10 | 농부 자동 전달 | 검증된 결제 완료 후 해당 농부에게만 발송. 전달 이력·실패·재전송·취소/변경 알림 제공 |
| F11 | 구매 후기 | 배송 완료한 구매 상품에 작성. 비회원도 주문 확인 후 이용. 작성자 수정·삭제, 운영자 숨김 이력 제공 |
| F12 | 상품 문의 | 문의 유형·답변 상태 표시. 비공개 문의는 작성자와 운영자만 열람. 비회원은 이메일 확인 후 이용 |
| F13 | 재입고·수확 알림 | 상품·종류별 이메일 확인 후 신청, 개별 해지. 비회원 지원. 같은 판매 회차 중복 발송 방지 |
| F14 | 사업자 견적 | 업체명·담당자·이메일·연락처·품목·수량·희망 납기·배송지 접수. 접수와 견적 확정 구분 |
| F15 | 농부·공동체 소개 | 실제 농부·농장·재배 이야기와 공동체 활동 표시. 예시 자료는 명시적으로 구분 |
| F16 | 고객센터 | 공지·FAQ·배송/교환 안내·문의, 실제 운영 정보와 정책 제공 |

## 3. 운영 정책표

아래는 개발 동작 기준이다. 실제 판매용 약관·환불 안내의 확정본은 운영 정보와 검토를 거쳐 오픈 전에 준비한다.

| 영역 | 개발 정책 |
|---|---|
| 가격·재고 | 원화 정수로 계산. 옵션별 판매 가능 수량 관리. 결제 진행 중 재고 확보·시간 만료 해제 및 결제 실패 복구 지원 |
| 배송 묶음 | 주문 아래 농부별 묶음 생성. 같은 농부 상품은 한 묶음. 농부별 배송비와 발송 예정일을 결제 전에 표시 |
| 배송비 | 농부별 기본료·무료배송 기준·추가지역 비용 설정. 미입력 상태와 0원을 구분. 필수 배송 정책 미설정 상품은 판매 불가 |
| 배송 지역 | 초기 국내 배송. 농부가 배송 가능 지역과 추가비용을 등록. 지원 불가 주소는 결제 전 차단 |
| 주문 상태 | 주문·결제·농부 전달·배송·환불 상태를 별도 관리. 고객에게 내부 전달 상태 미노출 |
| 운송장 | 농부가 운영자에게 전달하고 운영자가 등록. 농부별 택배사·운송장·발송 시각 기록 |
| 취소·변경 | 출고 전 요청을 접수해 운영자가 처리. 출고 후 요청은 고객센터 검토 흐름. 승인된 취소·변경은 농부에게 자동 알림 |
| 부분 취소 | 상품 금액·농부별 배송비·환불액을 서버에서 재계산하고 내역 보존. 정확한 고객 부담 기준은 판매 정책 확정 후 적용 |
| 주문 전달 | 발송 작업을 큐에 기록. 실패 시 1분·5분·30분 간격으로 최대 3회 자동 재시도 후 운영자 확인. 수동 재전송 이력 기록 |
| 전달 성공 | 발송 서비스 접수 성공을 의미. 농부 열람·실제 출고 완료와 구분. 이메일에는 만료 가능한 보안 주문 링크를 사용하고 배송 개인정보 본문 노출 최소화 |
| 주문 링크 | 추측 불가능한 토큰, 72시간 만료, HTTPS, 운영자 폐기·재발급 지원. 농부와 주문 묶음에 한정하여 접근 |
| 고객 알림 | 재입고는 품절→판매 가능, 수확 알림은 예정 상품의 판매 시작 시 발송. 1회 신청은 해당 판매 회차 발송 후 종료. 해지 링크 제공 |
| 후기·문의 | 공개 내용에 이메일·연락처·주소 표시 금지. 비공개가 문의 기본값. 후기는 확인된 구매자만 작성 |
| 견적 | 접수→검토→회신→종료 상태 관리. 최소 수량·단가·공급 가능 여부는 개별 회신 |
| 권한 | 운영자는 통합 관리. 고객은 본인 정보만 접근. 농부 링크는 배정된 주문 발송에 필요한 정보만 제공 |
| 정산 | 농부별 주문·취소·환불 내역 구분 및 내보내기 제공. 수수료·지급 주기 미확정이므로 자동 지급·정산액 확정 기능 제외 |

## 5. 후속 화면 목록 초안

2단계에서는 아래 화면의 상세 흐름·입력·상태를 설계한다.

- 고객: 홈, 장터, 상품 상세, 농부 목록·상세, 공동체 이야기, 고객센터·공지·FAQ.
- 계정: 가입, 이메일 확인, 로그인, 비밀번호 재설정, 마이페이지.
- 구매: 장바구니, 회원/비회원 선택, 주문서, 결제 진행·성공·실패, 주문 목록·상세, 비회원 조회·확인, 취소 요청.
- 소통: 후기 작성·수정, 상품 문의 작성·답변 확인, 견적 작성·접수 결과, 알림 신청·확인·해지.
- 운영자: 로그인, 상품·옵션·재고, 농부·배송 설정, 주문·운송장, 전달 이력·재전송, 취소·환불, 후기·문의·견적·알림·콘텐츠 관리, 농부별 주문 내보내기.
- 농부: 만료 가능한 주문 확인 링크 화면. 상품·재고·운송장 관리 기능은 제공하지 않는다.
